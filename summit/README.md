# Summit

A small precision platformer in the spirit of classic mountain-climbing
platformers: Phaser 3 + Vite, custom fixed-step physics, procedural pixel
art, WebAudio chiptune sound effects. Plays on desktop and on phones
(portrait or landscape).

**Movement constants:** all in [`src/config.js`](src/config.js); what each
one does is in [DESIGN.md](DESIGN.md).

## Controls

| | Keyboard | Touch |
|---|---|---|
| Move / aim | Arrows or WASD | d-pad (left), slide your thumb for diagonals |
| Jump | Z, C or Space | JUMP |
| Dash | X | DASH |
| Grab / climb | hold Shift or V | hold GRAB |
| Mute / pause | M / Esc or P | |

## Run it

```sh
npm install
npm run dev        # http://localhost:5173  (?room=3 jumps to a room, ?room=sandbox for the test room)
npm run build      # writes play/  (committed so it can be served statically)
npm test           # physics + route tests (Node, headless)
npm run e2e        # Playwright: build must exist; screenshots in tests/screens/
```

After changing rooms (`python3 tools/build_rooms.py`) or movement constants,
run `node tools/solver.mjs` to re-prove every room is beatable and refresh
`tests/routes.json`; `node tools/trace.mjs <room#>` draws the found route.

## Layout

```
src/config.js          every tunable constant
src/sim/               Phaser-free simulation: Player, World, Sim (runs in Node)
src/world/rooms.js     the 8 ASCII rooms (generated by tools/build_rooms.py)
src/scenes/            Boot (texture generation), Title, Game, End
src/gfx/Art.js         procedural sprites, tiles, backgrounds, pixel font
src/input/Controls.js  keyboard + multi-touch, latched presses per fixed step
src/audio/Sfx.js       WebAudio synth sound effects
tools/                 room builder, route solver, route tracer
tests/unit, tests/e2e  Node tests and Playwright tests
```
